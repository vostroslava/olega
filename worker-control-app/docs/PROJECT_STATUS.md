# Состояние проекта

## Текущий срез

- два существующих LaunchAgent описаны как управляемые сервисы;
- СтеклоСтройГрупп использует `gpt-5.6-luna` с reasoning `low` для чата;
- StaticCreo, СтеклоСтройГрупп и установленная копия Worker Control находятся на внутреннем диске пользователя;
- приложение проектируется как обычное Dock-приложение с дополнительным menu bar status.
- оба worker LaunchAgent временно выключены по запросу пользователя;
- StaticCreo control plane читает backend-профили и очередь при выключенном основном worker.
