# Важные решения

## 2026-07-15 — управление существующими LaunchAgent

Worker Control не устанавливает вторые экземпляры воркеров. Он управляет существующими plist и label, которые создаются собственными installer-скриптами StaticCreo и СтеклоСтройГрупп.

## 2026-07-15 — нативный SwiftUI и SwiftPM

Для локального системного интерфейса выбран SwiftUI на macOS 14+ и SwiftPM. Это даёт воспроизводимую сборку без отдельного Xcode-проекта и позволяет использовать системный sidebar, Settings, menu bar и `launchctl`.

## 2026-07-15 — ограниченный список настроек

Интерфейс редактирует только заранее разрешённые environment keys. Секреты, строки подключения и произвольные ProgramArguments в UI не показываются и не меняются.
